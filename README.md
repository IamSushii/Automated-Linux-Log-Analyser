Project: Automated Linux Log Analyzer
Role: Systems Administrator / Support Engineer Simulation

What I Built:
I engineered a Bash shell script within a Linux (Ubuntu) environment to automate the parsing of high-volume web server logs.

The Problem I Solved:
Instead of manually reading thousands of log entries, my script utilizes grep and awk to instantly isolate critical HTTP 500 (Server Crashes) and 401 (Unauthorized) errors. It automatically generates a clean diagnostic report for the engineering team and compresses the legacy log data via tar to optimize server disk space.
